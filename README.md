## Что отличается от opencode

- **Тема `verifactor`** по умолчанию: фон `#0a0a0a`, текст `#ecebe6`, оранжевый акцент `#ff5f1f`.
- **Пиксельный логотип и персонаж**, который перебирает лапками и моргает.
- **Загрузочный экран**: мерцающая сетка, сборка логотипа из пикселей, прогресс с этапами,
  пиксельное растворение в приложение. Пропускается любой клавишей.
- **Интерфейс на русском**: команды, диалоги, подсказки, справка по клавишам.
- **ИИ отвечает по-русски** — код, команды и имена файлов остаются как есть.
- **Агент и модель переключаются кликом** по строке под полем ввода.
- Пиксельный спиннер `▖▌▘▀▝▐▗▄`.

## Запуск

Нужен [Bun](https://bun.sh) 1.4+.

```bash
bun install
bun run dev
```

На Windows (cmd) — в конце укажи папку проекта, который хочешь открыть:

```bat
set BUN_OPTIONS=--preload G:/projects/verifactor-code/packages/cli/node_modules/@opentui/solid/scripts/preload.js&& cd /d G:\projects\verifactor-code\packages\cli && bun src/index.ts "C:\путь\к\проекту"
```

`BUN_OPTIONS` нужен потому, что фоновый сервер стартует из папки проекта и не видит
`packages/cli/bunfig.toml` с Solid-препроцессором JSX. Путь в нём — только с прямыми слэшами.

## Модели

Клик по названию модели под полем ввода → выбор модели. Чтобы подключить, например, Gemini:
«Подключить интеграцию» → Google → вставить API-ключ с aistudio.google.com/apikey.
